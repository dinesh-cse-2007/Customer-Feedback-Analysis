# Customer Feedback Analysis

**Customer Feedback Analysis** is a web-based application designed to collect, analyze, and visualize customer feedback. The system helps identify customer opinions, satisfaction levels, and common issues from feedback data.

## 🚀 Features

* 📝 Submit customer feedback
* 😊 Analyze positive, negative, and neutral feedback
* 🔍 Identify important keywords and common issues
* 📊 Display feedback statistics using charts
* ⭐ Customer satisfaction rating
* 📋 View and manage submitted feedback
* 📱 Responsive and user-friendly interface
* 💾 Store feedback data using browser local storage

## 🛠️ Technologies Used

* **HTML5** – Webpage structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and feedback analysis
* **Chart.js** – Data visualization
* **LocalStorage** – Client-side data storage

## ⚙️ How It Works

```text
Customer submits feedback
          ↓
Feedback is stored
          ↓
Text is analyzed
          ↓
Sentiment is identified
          ↓
Keywords and statistics are extracted
          ↓
Results are displayed on dashboard
```

## 📊 Analysis

The application provides information such as:

* Total feedback
* Positive feedback
* Negative feedback
* Neutral feedback
* Customer satisfaction percentage
* Frequently mentioned keywords
* Feedback trends

## 🎯 Objective

The main objective of this project is to help organizations understand customer opinions quickly and use feedback to improve their **products, services, and customer experience**.
